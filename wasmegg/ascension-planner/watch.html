Run watcher

Starting...

    Keep this tab open while the run goes; it can sit in the background. It checks about once a minute, and if the run's tab goes quiet for 2 minutes it opens the run's page again, which carries on by itself. It stops after 3 reopens in an hour, and when the run finishes or you press Stop.

    In Edge: add this site to Never put these sites to sleep (Settings, System and performance, edge://settings/system), and allow pop-ups for it (edge://settings/content/popups, Allow, Add). Without pop-ups allowed, this tab turns into the run's page itself instead.
